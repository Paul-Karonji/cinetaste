🎨 CineTaste UI & Color Palette Documentation

This document outlines the full visual identity and interface style for CineTaste, ensuring a consistent, premium, cinematic user experience across all devices. The design language is inspired by platforms like Netflix, Letterboxd, and modern dashboard apps—clean, stylish, dark, and immersive.

## 🎬 1. Visual Identity Overview

CineTaste aims to deliver a cinematic, emotional, and personalized movie discovery experience.
The UI communicates:

Premium quality

Warm cinematic contrast

Dark immersive atmosphere

Focus on visual content (posters & artwork)

User personalization and comfort

The design style is built around the “Cinematic Dark” palette—deep blacks, rich reds, soft whites, and subtle gradients.

🎨 2. Official Color Palette

The CineTaste palette is intentionally minimal to maintain focus:

Purpose	Color	Hex Code	Notes
Primary Brand Red	Bright Cinematic Red	#E50914	Used for major CTAs, highlights, logo
Secondary Deep Red	Deep Accent Red	#B81D24	Used sparingly for hover, secondary buttons, badges
Primary Background	Cinematic Black	#121212	Main background for all pages
Secondary Background	Dark Charcoal	#221F1F	Cards, headers, modals, sections
Neutral Light	Soft Off-White	#F5F5F5	Text, icons, low-contrast elements
Tone & Usage Notes

Reds are bold but never overwhelming.

Black background improves poster visibility and reduces eye strain.

Whites are soft, not pure white, to avoid glare.

Palette enhances emotional mood-based experiences.

🖼 3. UI Style Guide
### 3.1 Layout & Spacing

Minimal clutter — whitespace + breathing room.

Rounded corners (6–12px): modern yet subtle.

Large hero sections for movie artwork.

Smooth, fast animations on hover & transitions.

Spacing standard:

Padding: 16–24px

Column gap: 20px

Card spacing: 12–20px

### 3.2 Typography

Primary guiding principles:

Film-inspired, bold, clean.

Maximum readability on dark backgrounds.

Clear hierarchy.

Suggested structure:

Titles / H1: 32–42px, bold

Movie Titles / H2: 22–28px, medium

Body Text: 15–16px, regular

Muted Text: opacity 0.7–0.8

### 3.3 Buttons & Interactions
Primary Button

Background: #E50914

Text: #F5F5F5

Hover: #B81D24

Secondary Button

Background: #221F1F

Border: 1px #B81D24

Hover: Slight brightness increase

Micro Interactions

Poster hover: slight zoom-in (scale 1.03)

Red glow accent on selected items

Smooth fade transitions (150–300ms)

🎞 4. App Sections & How They Should “Feel”
## 4.1 Home Feed

Goal: Feel like entering a cinema library curated just for the user.

Huge banners featuring current watchlist items.

Smart suggestions in horizontal sliders.

Personalized “Continue Watching”.

Color usage:

Background #121212

Cards #221F1F

Highlights #E50914

## 4.2 MyWatch List

Goal: Organized, visual and easy to navigate.

Poster-first layout.

Filters + sorting on top.

Optional grid or compact list.

## 4.3 History Timeline

Goal: Feel like a visual diary.

Vertical or horizontal timeline.

Each watched item has:

Poster

Date watched

User rating

Red markers/icons for special events:

“Highest rated day”

“Most binge-watched day”

## 4.4 Mood Recommender

Goal: Emotional, atmospheric UI.

Dark blurred background based on selected mood.

Each mood has a color accent (soft glow):

Happy → Warm yellow glow

Sad → Cool blue

Thrilling → Deep red

Romantic → Soft pink

Suggestions appear in animated carousels.

## 4.5 Smart Auto Suggestions

Goal: Fast, intelligent, personalized.

Powered by watch history, ratings, moods, and categories.

Uses the main red accent very sparingly for emphasis only.

Movie cards dynamically change layout depending on recommendation confidence.

## 4.6 Ratings System UI

Goal: Fun, expressive, easy.

Big, centered rating modal.

Rating bar in bright red (#E50914).

Smooth slider animation.

Optional written review + emoji vibe check.

## 4.7 Profile & Multi-user Mode

Goal: Social, secure, customizable.

Features Design:

Profile page includes:

Avatar

Bio

Favorite genres

Public/Private toggle

“Friend” feature is clean:

Red accent around online friends

Grey muted profile cards for offline users

Privacy

Before anyone can follow or see your content:

Permission pop-up

Clear red/white accent buttons

🧭 7. Interaction Design Principles

User feels guided, not overwhelmed.

Posters and images speak louder than text.

Reds highlight actions—not decoration.

Dark UI blends into the background of the user’s room.

Animations must be smooth, subtle, and cinematic.
